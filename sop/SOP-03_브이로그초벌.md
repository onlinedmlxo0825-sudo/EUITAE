# SOP-03 브이로그 초벌 → CapCut 등록

- **언제:** 받아쓰기(SOP-02)가 끝난 뒤
- **요청 예시:** "의태 스타일로 편집해서 캡컷 프로젝트로 만들어 줘"
- **결과:** CapCut 프로젝트 목록 맨 위에 `<프로젝트>_초벌_vNNN`. 클립·자막·강조 글자가 각각 따로 들어 있다.

## 0. 준비

- **템플릿 프로젝트:** 영상 클립과 평소 자막 스타일의 텍스트가 든 CapCut 프로젝트. 지금은 `_template/capcut_v004`(v004 사본)를 쓰고 읽기만 한다. 소리 클립이 없어도 효과음 틀은 `vlog_build.py`가 만든다.
- **사람이 CapCut에서 고친 버전이 있으면** 다시 조립하기 전에 CapCut 쪽 `draft_content.json`과 `03_capcut`의 원본 사본을 비교한다. 고친 곳이 있으면 plan에 옮기거나 그 프로젝트 위에 수정한다.
- **CapCut:** 등록(`--install`) 전에 완전히 끈다.

## 1. 채널 스타일 기준 (의태)

- 길이 10~13분, 제목 형식 `[vlog] 무엇 l 한마디`
- **첫 20~30초는 하이라이트 몽타주** → 본편 → 짧게 끝내기("오늘은 끝")
  - 컷당 2~5초. 대사의 펀치라인만 남기고 설명하는 앞부분은 자른다
  - **낚시 장면 먼저**(웃긴 대사 → 입질 → "잡았다! 계속 감아라"), 그다음 **운동 중 힘들어하는 장면**(한 개만 하자, 마지막 반복, 빨개진 얼굴)
  - 먹는 장면이나 단순 개그(부스터 가루가 코로)로 시작하지 않는다(v004 피드백)
  - 화면이 바닥만 비추는 컷은 대사가 좋아도 쓰지 않는다
  - 하이라이트 구간 내내 위아래 검은 띠와 "● 하이라이트 미리보기" 라벨을 덮는다(`overlays`, `assets/highlight_letterbox.png`). 오른쪽 채널 이름은 넣지 않는다
  - 하이라이트 마지막 컷은 그날 가장 임팩트 있는 웃긴 장면으로 고르고, 거기에 `fade` [0, 1.2]와 `black` 1.8초를 붙인다. 제목 카드는 쓰지 않는다. **채널 이름과 제목 글자는 화면에 넣지 않는다**(v007 피드백)
  - (예전 방식, 쓰지 않음) 풍경 위에 `titles`로 "의태 VLOG 날짜"(노랑, 작게)와 그날 제목(흰색, 크게)을 띄운다. 검은고딕에는 가운뎃점(·) 글자가 없으니 쓰지 않는다
- **자막 모양**: plan의 `sub_box` {"color": "#000000", "alpha": 0.85, "radius": 0.15, "pad_x": 0.18, "pad_y": 0.16}, `sub_y` −0.82. 미리보기(`preview.py`)는 박스를 그리지 못하니 CapCut에서 확인한다
- **화면 글자 세 종류**: 운동 종목은 `cap_kind` "exercise"(→ `cap_styles.exercise`: Gothic A1 Black 흰 글씨 + 주황빛 빨강 #FF4A2B 둥근 박스, `cap_scale` 0.5), 상황 설명은 기본 `cap_style`(노란 검은고딕), 의태 속마음은 하늘색 `notes`. 대사만으로 상황을 알기 어려우면 한 줄을 덧붙인다
- **장면 전환**: 장소가 바뀌는 곳마다 앞 구간 `fade` [.., 0.8] → `black` 0.9초 → 다음 구간 `fade` [0.8, ..]. 그 자리 효과음(whoosh·snap)은 빼고, 새 장면 첫머리에 짧은 노란 글자를 넣는다
- **배경음악**: 장면마다 고른다. 운동은 보컬 없는 폰크·트랩 헬스 비트(뽕짝 느낌 신스 금지), 밥은 밝은 우쿨렐레, 낚시는 로파이, 라면은 가벼운 힙합. `bgm`마다 `fade_in` 1~1.5초, `fade_out` 2~2.5초를 주고, 전환 검은 화면(`장면 전환: …` 라벨)에서 끝나게 한다
- **말 대상**: 의태가 민준에게 묻는 말은 민준 세트 바로 뒤에 둔다. 글자는 그 동작이 일어나는 순간에 띄운다
- **비율**: 다음 영상부터 낚시:운동 = 7:3(적어도 6:4). 10분이면 낚시 약 7분, 운동 약 3분
- **의태 속마음 자막**: `notes`에 하늘색 `style` {"color": [0.55, 0.85, 1.0], "stroke_width": 0.1}, x 0.5, y 0.76, 배율 0.5. 민준이 한 말에 대한 반응("(그냥 올림 ㅋㅋ)"), 상황 설명("(낚시하고 와서 힘든 상태)")에 쓴다
- **말로 가리킨 장면은 넣는다**("등짝 큼지막" → 등을 찍은 장면). 민준 세트는 처음 4개와 마지막 3~4개로 마무리하고 다음 사람으로 넘어간다. 같은 사람이 세트를 끝내는 장면을 두 번 넣지 않는다
- **배경음악**: Pixabay에서 "Content ID Registered" 표시가 없는 곡만 `bgm/`에 받고, `bgm/CREDITS.md`에 출처를 적는다. plan의 `bgm` [{"file", "from_label", "to_label", "db"}]. 운동은 −30dB, 낚시는 −33dB. 하이라이트와 먹는 장면에는 넣지 않는다
- **이어 붙이기 점검**(v006 피드백)
  - 반응 대사("오 좋은데?", "15개 좋다") 앞에는 그 동작을 둔다. 민준 다음 의태 차례가 있으면 의태 세트를 넣는다
  - 종목 이름 글자는 첫 반복 때 띄운다(고르거나 세팅할 때가 아니다)
  - 핵심 동작(면을 집어 들기, 감기)과 말이 끝난 뒤에 넘긴다
  - 원인과 결과 순서로 놓는다(꽝 → 발 젖음 → 차에서 장화 → 정비 → 2차전). 결과 장면이 없으면 노란 글자나 사진으로 채운다
  - 작은 설명 글자(`notes`, 흰색, 배율 0.42)는 설명하는 물건 바로 옆에 둔다
  - 웃긴 실수에는 효과음과 머쓱한 글자를 넣는다(snap + "ㅋㅋㅋㅋ" + cricket "(머쓱)", whoosh + "안녕히 계세요 여러분~", buzz + "꽝!")
  - 검은고딕에 없는 글자(…, ·, →)는 화면 글자에 쓰지 않는다. 미리보기에서 빈칸으로 나오는지 확인한다
- **운동 세트 정리**
  - 종목당 1~3세트만 넣는다. 의태 세트가 더 많아야 하고, 민준은 종목당 많아야 1세트
  - 몸이 좋아 보이거나 웃긴 장면(한 개만 하자, 비명, 표정)이 있는 세트를 고른다
  - 사람은 옷으로 구분한다(11/8 기준: 민준은 흰 티, 의태는 검은 민소매). 세트마다 프레임 한 장씩 뽑아 누구인지 확인한다
  - 개수는 앞 1~5개와 마지막 3~5개만 남기고 가운데는 자른다. "하나~" 하고 뜸 들인 빈 곳도 자른다
  - 컷 위치는 숫자 낱말 시각으로 잡는다. 받아쓰기 숫자 잡음("6", "8")은 단어 가운데 시각이 구간 밖에 오도록 컷을 옮겨서 뺀다
  - v002의 티저(긴 클립 5개, 33초)는 "첫 도입부가 너무 재미가 없어"라는 피드백을 받았다
- 본편은 **운동 먼저, 그다음 낚시**(먹방은 그 사이나 끝). 실제 촬영 순서가 달라도 이 순서를 따른다
- **말 더듬은 곳은 자른다**: 다시 시작한 말의 앞쪽, 말하다 만 조각, 문장 끝 군말, 3초 넘게 빈 곳. 한 클립을 여러 구간으로 나눠 plan에 적는다. 일부러 반복한 개그("바닥 또 걸렸다" ×3)는 남긴다
- **물고기를 건 장면은 결과를 밝히지 않는다**: "잡았다! 계속 감아라"에서 끊고, 밑걸림·바닥 걸림 대사는 그 장면 근처에 두지 않는다
- **효과음은 조금만**: 1분에 약 1.5개, 하이라이트에는 3개. 실패 wahwah·buzz, "잡았다"·사진 ding, 장 전환 whoosh·snap, 머쓱 cricket. 강조 글자마다 넣는 pop(뽀잉)과 boing은 쓰지 않는다(v006 피드백)
- 순서를 바꾸면 그 순서와 안 맞는 대사(예: "낚시하고 운동하면 안 되겠다")는 뺀다
- 자막: 흰 글씨에 검은 테두리, 화면 아래 가운데, 말한 내용 그대로
- 운동 구간: 종목 이름을 글자로 띄운다
- 화면 위 강조 글자는 자막과 **다른 굵은 글꼴**로 넣는다(`cap_style`). 지금은 `fonts/BlackHanSans-Regular.ttf`(검은고딕, 무료·OFL)에 노란 글씨와 검은 테두리를 쓴다. v003의 한컴 고딕 Bold는 평범한 고딕이라 예능 느낌이 약했다
- 배경음악은 사람이 고른다(초벌에는 넣지 않는다)

## 2. 장면 고르기

- `01_asr/*/transcript.txt`와 `00_sheets/*.jpg`를 보고 살릴 대사와 장면을 고른다. 애매하면 남긴다.
- 구간의 시작은 첫 단어보다 0.2~0.3초 앞, 끝은 마지막 단어보다 0.3~0.5초 뒤로 잡는다(`words_in.py`).
- 받아쓰기 오류는 `replace`에 적는다. 특히 엉뚱한 말이나 비속어로 잘못 받아쓴 곳은 꼭 고친다.

## 3. `02_plan/plan_vNNN.json` 쓰기

| 키 | 뜻 |
|---|---|
| `name` | CapCut 프로젝트 이름(기존 이름과 겹치면 등록 거부) |
| `template` | 템플릿 프로젝트 폴더 |
| `asr_root`, `staging` | `01_asr`, `03_capcut` 경로 |
| `sub_scale` | 자막 크기(클립 배율). **0.45**를 쓴다. 0.7은 화면 밖으로 잘렸고(v001), 0.55도 "아직도 크다"였다(v002) |
| `sub_max` | 자막 한 줄 글자 수 `[나눌 목표, 최대, 한 줄로 둘 최대]`. **[20, 26, 22]** |
| `cap_scale` | 강조 글자 크기. **0.6** |
| `cap_style` | 강조 글자 모양 `{"font": 글꼴 파일, "color": [r,g,b], "stroke": [r,g,b], "stroke_width": 0.1}`. 넣으면 자막 프리셋 대신 이 모양을 쓴다 |
| `cover` | 표지 프레임 `[파일, 초]` |
| `replace` | 자막 표기 고치기 `{"틀린 말": "고칠 말"}` |
| `sfx_dir` | 효과음 폴더(`클로드 영상편집/sfx`) |
| `bgm` | 배경음악 `[{"file": mp3, "from_label", "to_label", "db": -30, "fade_in": 1.5, "fade_out": 2.0}]`. 구간 안에서 곡을 반복해 깐다(`BGM` 트랙) |
| `sub_box`, `sub_y` | 자막 박스, 자막 세로 위치 |
| `cap_styles` | 글자 종류별 모양 `{"exercise": {"font", "color", "stroke_width", "box": {...}}}`. 구간에 `cap_kind`, `cap_scale`를 적는다 |
| `overlays` | 그림 덮기 `[{"file": png, "from_label": 시작 구간 label, "to_label": 끝 구간 label, "track": "하이라이트 표시"}]` |
| `segments[]` | `file`, `in`, `out`(원본 초), `subs`(자막 넣을지), `label`(메모), `caption`(강조 글자), `cap_offset`, `cap_dur`, `cap_end`, `cap_y`, `cap_size`, `cap_sfx`·`cap_sfx_db`(강조 글자가 뜰 때 소리), `sfx`(`[{"name": "ding", "src": 원본 초 또는 "at": 구간 안 초, "db": -15}]`), `vol`(원본 소리 배율), `fade`(`[들어올 때 초, 나갈 때 초]`), `titles`(`[{"text", "at", "dur", "y", "scale", "style": {"color", "stroke_width"}, "fade"}]`), `notes`(`[{"text", "src" 또는 "at", "dur", "x", "y", "scale", "size", "style", "sfx", "sfx_db"}]` → `강조 글자` 트랙), `black`(검은 화면 유지, 소리 끔). 사진 구간은 `{"file": "x.jpg", "dur": 4.5}` |

## 4. 조립하고 자막 훑어보기

```powershell
python -I scripts\vlog_build.py "$HOME\.claude\skills\smartdaddy-video-edit\scripts" ".\<프로젝트>\02_plan\plan_vNNN.json"
```

`03_capcut/<이름>_timeline.json`의 `subtitles`를 처음부터 끝까지 읽는다. 이상한 표기는 `replace`에 추가하고 다시 조립한다.

## 5. 미리보기 프레임

```powershell
python -I "$HOME\.claude\skills\smartdaddy-video-edit\scripts\preview.py" ".\<프로젝트>\03_capcut\<이름>" ".\<프로젝트>\04_preview\t_<초>.mp4" --h 540 --start <초> --end <초+2.5>
```

템플릿 글꼴(CapCut 내장 `en.ttf`)은 미리보기에서 한글이 네모로 나온다. 확인용으로는 `draft_content.json`을 임시 폴더에 복사하고, 그 안의 `SystemFont/en.ttf`를 `SystemFont/ko.ttf`(CapCut 내장 한글 글꼴)로 바꾼 사본으로 미리보기를 만든다. 등록하는 원본은 바꾸지 않는다. 미리보기는 자막 프리셋의 그림자를 그리지 않으니 최종 모양은 CapCut에서 본다.

## 6. CapCut 등록

CapCut을 끈 뒤 4번 명령에 `--install`을 붙인다. 프로젝트 목록 파일은 `03_capcut/backups/<시각>/`에 백업된다. 같은 이름이 이미 있으면 등록을 거부하므로 `name`을 `_v002`처럼 올린다.

## 7. 보고

길이, 클립·자막·강조 글자 개수, 그리고 확인이 필요한 곳(이름 표기, 뜻이 애매한 받아쓰기, 미리보기로 확인하지 못한 부분)을 알린다.
